# 闭月定格消耗侧；迟到用量进未定格月

闭月后**消耗金额、代金券扣费、扣费金额**不再现算、不再改写。这取代 ADR-0007/0008/0009 中「消耗与 token 始终现算、延迟入账可改历史月」的表述。

**应收金额不定格**：闭月后仍随账单调整、补偿发券变化（ADR-0018：应收 = 消耗 + 调整 − 发券）。补充 PRD 曾把应收也写成不可再变，与代码不符，以代码为准。

闭月之后才入账的用量不回撕已定格月，进入首次可写的未定格月（通常是当前月）。对账 Excel 对消耗侧定格、不回写；差异走后台账单调整与报表。

Status: accepted (supersedes the live-recompute-for-closed-months parts of ADR-0007, 0008, 0009)
