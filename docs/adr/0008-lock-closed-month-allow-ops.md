# 闭月冻结默认死线；当月禁核销/调整/延期

每个自然月在北京时间次月 1 日 00:00:00 闭月。闭月后把当时的回款天数和默认账期截止时间幂等冻结（第一次读取或回扫即可）；此后改授信或回款天数不挪已有月的死线，只有延期事件能改那一个月。

当月账单行加「当月」标签：账单核销、账单调整、延期置灰；**补偿发券与下载可用**。已结束月份才能核销/调整/延期。当月 UI 可含当天消耗；当月 Excel 明细截止昨天 23:59:59（北京时间），文件名标「未定格」。消耗侧定格见 ADR-0013。
