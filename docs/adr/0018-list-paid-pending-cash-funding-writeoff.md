# 列表已付款含现金/清偿/核销；待付款扣发券

企业账单列表「已付款 / 待付款」不再等于「仅核销累计 / 扣费+调整−已付款」。运营要看扣费口径下还差多少现金：已付款含当月余额实扣、授信充值清偿和线下核销；待付款再减去补偿发券。Excel 明细仍按行级渠道拆分，不跟列表列。这取代 ADR-0016「发券不参与待付款」。

## 列表已付款金额

```
已付款 = ① 现金/赠款消耗 + ② 授信 FUNDING 清偿 + ③ 账单核销
```

| 项 | 归月 | 取数 |
| --- | --- | --- |
| ① 现金/赠款消耗 | 分摊 `createdAt` 的北京时间自然月（消费日 ∈ 账单月） | `balance_consumption_allocations`：`source ≠ ENTERPRISE_CREDIT` **或** 挂了 `balance_grant_id`；金额取 `recognizedRevenueUsd`（本金，不含用券） |
| ② 授信 FUNDING | **被清偿那笔消耗**的消费日所在月，**不**按清偿到账日 | `enterprise_credit_settlements`：`trigger = FUNDING`；金额取 `amountUsd`。九月欠款、十月充值记进九月。预付款账户 ② = 0 |
| ③ 账单核销 | 事件挂月 | 已确认 `WRITE_OFF` 的 `amountCents` 累计 |

预付款无 ① 分摊记录时回退：已付款 = 扣费金额 + ③（余额实扣口径）。授信纯垫付分摊（`source = ENTERPRISE_CREDIT` 且无 grant）不进 ①。

## 列表待付款金额

闭月用定格扣费；当月用现算扣费。

```
待付款 = max(0, 扣费金额 + Σ调整 − Σ发券 − 已付款)
扣费金额 = 消耗金额 − 代金券扣费
应收金额 = 消耗金额 + Σ调整 − Σ发券   （收入口径；发券仍冲应收）
```

调整、发券来自该月已确认 `ADJUST` / `COMPENSATE_VOUCHER`。待付款恒 ≥ 0；调减使括号内为负仍允许落库，展示按 0。应收闭月后仍随调整/发券变化，不在定格集合里（ADR-0013）。

## 不在本口径

Excel「账单明细」行内已付款 / 待付款 / 结算状态仍走渠道拆分（ADR-0012），与上表不是同一列。账户信息已用信用仍走垫付占用（ADR-0017），不随列表待付款覆盖。
