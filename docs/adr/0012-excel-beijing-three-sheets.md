# 0012 企业账单 Excel：北京时间、三 sheet、口径进文件名

ADR-0003 定了下载时区只用北京时间。ADR-0009 曾要求每个 sheet 标「数据截至」；实现改为写进导出文件名，不写进 sheet。

1. 三个 sheet 固定为 **账单汇总 / 产品模型汇总 / 账单明细**，对齐 `docs/pr-enterprise-account-refactoring/2026-XX- XX公司-账单.xlsx` 模板。不再有「调整与核销」独立 sheet——账单调整与账单核销折进账单汇总（调整金额、已付款金额），不单独成表。
2. 所有时间戳（数据截至、账期截止时间、明细自然日）一律北京时间；明细按北京时间自然日切分，跨日不拆断整天。不使用 UTC `toISOString()`。
3. 每个 sheet 第一行标题只放公司名—sheet 名；第 2 行账期；**第 3 行起为列头**。统计口径「数据截至 {yyyy年MM月dd日HH:mm:ss}{未定格|已定格}」**不写进 sheet**，去掉空格/冒号/逗号后放进导出文件名并用括号括上，例如 `2026-09-XX公司-企业账单-(数据截至2026年09月30日235959已定格)-yyyyMMdd-HHmm.xlsx`。当月截止昨天 23:59:59；已定格月截止该自然月最后一天 23:59:59（北京时间）。明细与渠道拆分窗口同此截止，不含次月及以后；不以 `amountsFrozenAt` 作业时刻截断。
4. 明细列：账期（自然日）、账户ID、模型、类型（输入/输出/缓存命中）、用量、目录价格、单价单位、折扣、币种、消耗金额，与模板列对齐。
