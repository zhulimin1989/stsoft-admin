# 现算消耗的三个配套规则

当前月消耗按北京时间自然月现算之后，必须同时成立：

1. 账户信息已用信用是垫付占用，不是待付款合计；网关可花额度仍是钱包 + 有效信用（ADR-0017）。
2. 死线到达时还不是待核销的月份，事后才因延迟用量变为待核销的，不回溯自动停授信（ADR-0011）。
3. 企业账单 Excel 的统计口径写进导出文件名括号，不写进三个 sheet；当月明细截止昨天 23:59:59（北京时间），已定格月截止该自然月末（ADR-0012）。切月按北京时间，不复用现网 UTC 月汇总 SQL。
