# V2 企业账单核销与调整只改账单、不加减钱包余额

企业账户 V2「企业账单」tab 的【账单核销】【账单调整】只写 `enterprise_bill_events` 并重算该月已付款 / 调整金额 / 待付款。**不**调用钱包入账，不加减 `wallet.balanceUsd`，不走充值 FIFO，也不再按「其他变动」联动余额。

钱怎么进钱包仍走账户头 V1 充值（先填授信坑再补余额）或旧抽屉「调整余额」。补偿发券仍发券资产、仍不改余额。延期本来就不碰钱包。

这取代 ADR-0014（核销/调整按其他变动加余额）和 ADR-0015（调增可把钱包打成负）。那两份只适用于已废弃的「账单按钮联动钱包」口径。

Status: accepted (supersedes ADR-0014, ADR-0015)
