# 企业账单操作落事件；消耗侧闭月定格

企业账单不是一张冻死的完整快照。账单核销、账单调整、延期、补偿发券写成事件，按账单月折到展示行上。默认账期截止时间在闭月后冻结，见 ADR-0008。

当前北京月的消耗、代金券扣费、token 从用量现算（北京时间自然月，不复用 UTC `DATE_TRUNC`）。已闭月的消耗侧按 ADR-0013 定格，不再现算。旧钱包调整余额与充值 FIFO 清偿不改；V2 账单按钮不碰钱包见 ADR-0019。
