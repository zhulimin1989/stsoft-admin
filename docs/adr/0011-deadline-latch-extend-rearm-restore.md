# 0011 死线闩值与延期重新武装、自动恢复

ADR-0004 定了「死线到达时还不是待核销、之后才因延迟用量变成待核销的月份不回溯停授信」。实现上把「死线时是否待核销」落闩到 `pendingAtDeadline`，但闩值只在死线后第一次回扫/读取时惰性写入，不是死线时刻的真值——死线与回扫之间进来的延迟用量会被算进去，所以这是近似语义，依赖 60s sweep 把窗口压到可接受。

两条配套规则：

1. **EXTEND 重新武装死线**：落闩只对当时生效的账期截止时间成立。延期后旧闩作废（清空 `pendingAtDeadline`/`pendingObservedAt`），新死线到达时再按当时的消耗+事件重新观察。
2. **自动恢复**：所有「死线时待核销且已过期」的账单未核销 ≤ 0 后，被逾期作业自动停用的授信恢复为 ACTIVE。人工暂停（SUSPENDED 但无逾期账单）不参与恢复；只有 `evaluateOverdue` 判定非逾期时才把 SUSPENDED 拉回 ACTIVE。
