## 实现覆盖（稿面不要照抄）

| 稿面 | 实现 |
| --- | --- |
| 列表「数据样式不变」 | V2 列表按 §3 **重做**；旧列表原样保留 |
| 详情头出现「调整余额」的旧图 | V2 **没有**该按钮；改应收走行内账单调整 |
| 账单调整的归属账单月 / 入账月 | **不做** |
| 下载 UTC / 北京 双选 | 弹窗仅北京时间，确认后下载 |
| 当月行仍可核销/调整/延期，或文字 PRD 写不加标签 | 加「当月」标签；三按钮置灰，只能下载 |
| 核销弹窗无备注 | 加非必填备注 ≤100 |
| 消耗「不可变」快照 | 消耗永远现算；运营不能手改 |
| 授信自动失效放二期 | 本期企业账户按月账单做自动失效/恢复（billing） |
| 手机号脱敏图 | 列表与详情 **明文** |
| 切月用现网 UTC 月汇总 | 按 **北京时间** 自然月，不复用那条 SQL |

样式复用现有 Admin 规范（FilterBar、表格、弹窗、金额红字），新页面放 V2 文件，不改旧页。
