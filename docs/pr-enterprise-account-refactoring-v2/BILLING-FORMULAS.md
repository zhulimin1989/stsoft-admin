# 企业账单 · 核心公式与统计口径

> 与 `CONTEXT.md` 配套。本文只记**正典公式**与**场景边界**，实现细节见 ADR。  
> 正典以 billing `enterprise-bills.policy.ts` / `enterprise-account.service.ts` 为准；PRD 旧句「应收=扣费、调减不可负、发券互斥」已作废。

---

## 0. 统计口径（两场景共用）

| 规则 | 说明 |
| --- | --- |
| **月度独立** | 每个自然月单独算。账单调整、对账、已付款、待付款、调整金额均**不跨月累计**。 |
| **一行一月** | 一行 = 一个企业账户 × 一个北京时间自然月。 |
| **资金扣减优先级** | 代金券 → 余额 → 信用额度（用量发生时）。 |

---

## 1. 账单调整场景（后台「企业账单」sheet）

运营在 Admin 账单行上做**账单核销 / 账单调整 / 延期 / 补偿发券**时使用的口径。

### 1.1 公式（代码）

```
扣费金额     = 消耗金额 − 代金券扣费   （定格 / Excel / 写汇总；后台列表不展示、不现算）
应收金额     = 消耗金额 + 调整金额 − 发券金额
待付款金额   = max(0, 扣费金额 + 调整金额 − 发券金额 − 已付款金额)
已付款金额   = 现金/赠款消耗 + 授信 FUNDING（预付款不计 FUNDING）+ 账单核销
             预付款且现金/赠款 = 0 时回退为 扣费 + 账单核销
```

闭月后**定格**：消耗金额、代金券扣费、扣费金额。迟到用量不进已定格月，进首次可写的未定格月（ADR-0013）。

闭月后**仍可变**：应收金额（随调整/补偿发券）、调整金额、发券金额、已付款金额、待付款金额。

### 1.2 已付款取数（列表列）

见 ADR-0018。现金/赠款与 FUNDING 均按分摊 `created_at` 的北京自然月归月，不是清偿到账日。

### 1.3 账单核销

| 项 | 规则 |
| --- | --- |
| 校验 | 金额 > 0、精确到分、≤ 当前待付款；待付款 = 0 时按钮置灰 |
| 账单行 | 已付款 += 核销额；待付款随公式重算 |
| 用户侧余额 | **不**加减（ADR-0019） |
| 已用信用 | **不**单独记账；账户信息走 V1 垫付占用 |

文案：行内与弹窗均用「账单核销」。

### 1.4 账单调整

| 项 | 规则 |
| --- | --- |
| 方向 | 调增 / 调减；金额恒正；调减记入调整金额为负 |
| 校验 | 金额 > 0、原因必填 ≤100 字；**调减使括号内为负仍允许落库**，待付款钳制为 0 |
| 账单行 | 改调整金额；应收与待付款随公式重算（应收不定格） |
| 用户侧余额 | **不**加减（ADR-0019） |
| 已用信用 | 账户信息走 V1 垫付占用，不随待付款覆盖 |
| 与补偿发券 | **无硬互斥**；当月禁调整、允许补偿发券；补偿要求已付款 > 0 且金额 ≤ 已付款 |

### 1.5 状态与逾期（账单调整场景）

| 项 | 规则 |
| --- | --- |
| 待核销 | 已付款 = 0 **且** 待付款 > 0 |
| 已核销 | 其余（含部分回款：已付款 > 0 仍可能有待付款） |
| 逾期停授信 | 状态 = 待核销 **且** 过账期截止时间 **且** `pendingAtDeadline`（部分回款不关闸） |
| 临期标红 | 待付款 > 0 且剩余账期 < 10 天；待付款 = 0 **不**因清账标红 |

### 1.6 账户信息（V1 垫付占用）

```
已用信用     = Σ(已批准授信垫付 − 已结清)     GET 读 funding 快照
剩余信用     = max(0, 有效信用 − 已用信用)
余额         = 财务对账流水最新一条变动后余额（无流水则空）
账户可用余额 = max(0, 余额) + 剩余信用
```

不是各月待付款之和。账单核销 / 调整不覆盖账户信息这三列。

### 1.7 演示勾稽（账单调整场景）

起点：消耗 = 扣费 = 5,420；调整 −1,200；发券 0；已付 2,000  
应收 = 5,420 − 1,200 = **4,220**；待付款 = 5,420 − 1,200 − 2,000 = **2,220**

| 操作 | 应收 | 调整 | 已付 | 待付款 |
| --- | --- | --- | --- | --- |
| 调减 1,000 | 3,220 | −2,200 | 2,000 | 1,220 |
| 核销 1,220 | 3,220 | −2,200 | 3,220 | 0 |
| 再调增 500 | 3,720 | −1,700 | 3,220 | 500 |

## 2. 对账场景（Excel `2026-XX- XX公司-账单.v2.xlsx`）

自然月结束后导出；**导出即定格，不回写**。对账差异只走后台账单调整 + 报表，不改已导出文件。

导出明细窗口（北京时间）：
- **未定格当月**：截止昨天 23:59:59（`[月初, 今天 00:00)`）
- **已定格月**：截止该月最后一天 23:59:59（`[月初, 次月 1 日 00:00)`），不含次月及以后；不按定格作业时刻截断

### 2.1 三 sheet

| Sheet | 内容 |
| --- | --- |
| 账单汇总 | 按账号：用量、目录总价、折后金额、折扣、占比；底栏：合计（消耗金额）→ 代金券扣费 → 应收金额 |
| 产品模型汇总 | 按模型：用量、目录总价、折后金额、折扣、占比 |
| 账单明细 | 行级：账期（自然日）、账户 ID、模型、类型、用量、目录价格、单价单位、折扣比、币种、总消耗金额、信用支付金额、代金券抵扣金额、已付款金额、待付款金额、结算状态 |

### 2.2 明细行勾稽（对账场景 · 行级资金渠道）

```
总消耗金额 = 信用支付金额 + 代金券抵扣金额 + 已付款金额 + 待付款金额
```

此处「已付款金额」是**该行消耗被余额实扣**的部分，与后台列表「现金/赠款 + FUNDING + 核销」的已付款**不是同一口径**（见 CONTEXT「已付款金额」）。

### 2.3 两类客户（对账场景）

| 客户分类 | 明细特征 |
| --- | --- |
| 授信用户 | 可有信用支付、代金券、待付款、结算状态；无充值时行内已付款可为 0 |
| 预充值用户 | 信用支付 = 0；正常已付款 = 总消耗（余额扣），结算状态「已结算」；余额耗尽时末笔可能「未结算」 |

两类均：**代金券优先抵扣**。

## 3. 两场景对照（易混点）

| 概念 | 账单调整场景（后台列表） | 对账场景（Excel 明细） |
| --- | --- | --- |
| 已付款金额 | 现金/赠款消耗 + FUNDING（消耗日归月）+ 账单核销 | 该行余额实扣金额（渠道拆分） |
| 待付款金额 | max(0, 扣费 + 调整 − 发券 − 已付款) | 行级未结清渠道份额 |
| 应收金额 | 消耗 + 调整 − 发券（闭月后仍可变） | 汇总底栏；与列表公式同一应收，导出不回写 |
| 调整 | 改调整金额 / 应收 / 待付款；不回写 Excel | 导出后不体现；差异只在后台与报表 |
| 跨月 | **禁止**跨月累计 | **禁止**跨月累计 |

## 4. 取数口径与定时任务

企业账单列表（含已定格闭月）按 Excel 账单汇总现算请求数 / token / 消耗，不读定格快照。refresh/close 仍写月汇总并定格消耗侧。后台账单列表 GET 不返回、不现算代金券扣费与扣费金额列（ADR-0020）。

| 指标 | 读 | 写 |
| --- | --- | --- |
| 账单月 请求数 / token / 消耗 / 三渠道 / 已付 / 待付（企业账单 tab 列表） | 每个月现算，与 Excel 账单汇总同一窗口；不读 deadline 定格快照 | refresh/close 仍写 `enterprise_bill_month_summaries`（账户列表 usedCents 等） |
| 已用信用 | `enterprise_funding_snapshots` | refresh 末尾按 allocation SUM upsert |
| 余额 | `balance_transactions` 最新一条 `balance_after_usd` | 流水自然产生，无作业 |
| 账期到期时间 | 待付款 > 0 月里最早死线（月汇总或现算） | 随 refresh/close 写入 `effectiveDueAt` |

K8s CronJob（Asia/Shanghai，Forbid，打 billing ClusterIP）：

| 作业 | 路径 | 时刻 |
| --- | --- | --- |
| 刷新当月快照 + 垫付占用 | `POST /internal/billing/admin/v2/enterprise-bill-month-summaries/refresh` | `*/15 * * * *` |
| 关闭历史月 | `POST /internal/billing/admin/v2/enterprise-bill-month-summaries/close` | `5 0 * * *` |

Admin 同名路径只做 JWT 代理。close 抢不到 session advisory lock 时 skipped + hasMore，等下一轮。
